# Changelog

## 0.1.0 - 2026-10-07

First public release (beta).

### Added
- RTS overseer view: rise above the world, box-select and command villagers, golems, pets and mod NPCs with control groups and a command bar.
- Orders: move, hold, follow, guard, patrol, roam, home, come, rally; remote trading; village cards (people by job, mood, reputation, danger).
- Command Baton, War Table and Rally Flag (Blockbench models); option to hide your hand and body in the view; `/oversee`.
